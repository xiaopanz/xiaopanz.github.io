Research Projects

  • CoReNav: Conformal Calibrated Foundation Model Rewards for Object Navigation
    • Proposed a compute-efficient object-goal navigation framework that combines imitation learning with reinforcement learning fine-tuning driven by foundation-model-based rewards, enabling semantically guided exploration without continuous high-latency model querying.
    • Applied conformal prediction to calibrate foundation-model outputs in the navigation loop, including VLM-based room classification and LLM-generated object relevance priors, producing trust-aware rewards that mitigate hallucinations and stabilize RL fine-tuning.
    • Evaluated on the HM3D Semantics dataset, showing improvements over baselines in success rate, path optimality, and time efficiency in photo-realistic environments.
  • CommCP: Efficient Multi-Agent Coordination via LLM-Based Communication with Conformal Prediction (ICRA 2026)
    • Formulated the information-gathering process for natural-language assignments as a multi-agent multi-task embodied question answering (MM-EQA) problem, where robots collaborate in a shared environment and communicate to exchange information and answers.
    • Proposed CommCP, an LLM-based decentralized communication framework for MM-EQA that uses conformal prediction to calibrate generated messages, reducing distractions to other agents while improving communication reliability and efficiency.
    • Created an MM-EQA benchmark with photo-realistic scenarios from the HM3D dataset and released it to facilitate future research.
  • LaMMA-P: Generalizable Multi-Agent Long-Horizon Task Allocation and Planning with LM-Driven PDDL Planner (ICRA 2025)
    • Introduced LaMMA-P, a framework that integrates LLM reasoning with PDDL planning heuristics to solve long-horizon task planning for heterogeneous robot teams with a flexible number of agents.
    • Developed a modular system design that connects LLMs, PDDL planners, and simulation environments to support flexible task decomposition and efficient sub-task allocation based on robot skills and capabilities.
    • Created MAT-THOR, a benchmark of multi-agent long-horizon tasks based on AI2-THOR with standardized tasks and metrics, achieving state-of-the-art success rate and efficiency.
